# ระบบจองคิวช่างภาพ & สื่อประชาสัมพันธ์ (Photographer Booking System)

ระบบจองคิวช่างภาพอัจฉริยะ ออกแบบมาเพื่อบริหารจัดการคิวงานช่างภาพ การบันทึกภาพนิ่ง และวิดีโอสำหรับองค์กร ทันสมัย สะดวก รวดเร็ว พร้อมเชื่อมต่อฐานข้อมูลแบบเรียลไทม์

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **เลือกประเภทบริการถ่ายภาพ (Service Options)**:
   - 📸 **บริการถ่ายภาพนิ่ง (Still Photography)**: บันทึกภาพบรรยากาศงานประชุม, สัมมนา, พิธีการ, ภาพหมู่
   - 🎥 **บันทึกวิดีโอ & วิดีโอไฮไลท์ (Videography & Highlights)**: บันทึกวิดีโอตลอดงาน, สัมภาษณ์ผู้บริหาร, จัดทำคลิปไฮไลท์
   - 🎬 **แพ็กเกจครบวงจร ภาพนิ่ง + วิดีโอ (Full Coverage)**: บริการครบจบในงานเดียว พร้อมไฟสตูดิโอและไมค์ไร้สาย

2. **ระบบตรวจสอบการจองซ้ำซ้อน (Overlap Prevention)**:
   - ป้องกันการจองคิวงานในวันและช่วงเวลาเดียวกันโดยอัตโนมัติ

3. **ตารางแสดงคิวงาน (Schedule Table & Calendar)**:
   - ตารางแสดงรายการคิวงาน วัน เวลา สถานที่ ผู้จอง และสถานะคิวงาน
   - ปฏิทินแสดงภาพรวมวันที่ติดคิวงานในแถบด้านข้าง
   - ช่องค้นหาด่วน (Search) ค้นหาจากชื่องาน ผู้จอง หรือสถานที่ได้ทันที

4. **ฐานข้อมูลเรียลไทม์ (Real-time Sync & Offline Fallback)**:
   - รองรับ Firebase Realtime Database (แยก node เป็น `photographer_bookings`)
   - รองรับ LocalStorage อัตโนมัติในกรณีออฟไลน์หรือไม่พบการเชื่อมต่อ Firebase

5. **รองรับ Dark Mode / Light Mode**:
   - ปรับเปลี่ยนธีมสว่าง/มืด พร้อมบันทึกสถานะลงในเบราว์เซอร์

---

## 📁 โครงสร้างไฟล์ (File Structure)

- `index.html` : โครงสร้างหน้าเว็บ หน้าฟอร์มจอง และตารางแสดงคิวงาน
- `style.css` : สไตล์การตกแต่ง ดีไซน์ Glassmorphism และ Responsive
- `app.js` : ลอจิกการทำงาน การเชื่อมต่อฐานข้อมูล การคำนวณวันเวลา และระบบตรวจสอบคิว
- `S__237256707.jpg` : รูปโปรไฟล์ทีมงานช่างภาพ
